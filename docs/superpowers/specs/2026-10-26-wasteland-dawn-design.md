# 求生 Survival — 设计文档（原《废土黎明 Wasteland Dawn》）

> **⚠️ 已废弃（2026-10-28）**：本文描述的是 Phaser 2.5D 顶视角守家方案，项目已在 2026-10-28 整体重做为 **Three.js 第一人称射击 + 程序化小镇**，素材与 Phaser 全部移除。
> 现行设计文档：[2026-10-28-fps-town-design.md](2026-10-28-fps-town-design.md)。本文仅作历史参考，其中的玩法与数值均不再生效。

- 日期：2026-10-26
- 状态：已批准（玩法设计 + 技术架构均已确认）
- 类型：斜俯视 2.5D 即时生存 + 塔防式守家（浏览器 2D 游戏）

## 1. 游戏概览

玩家在废土中经营一个小型基地：白天外出搜集物资、布置防御，夜晚对抗一波波丧尸潮。无尽模式，难度逐日递增，死亡后结算存活天数并记录历史最高纪录。

- 核心幻想：废土拾荒者，靠双手和破烂防线在末日里多活一天是一天
- 玩家动词：移动、采集、建造、补枪、修理
- 目标体验：白天张弛有度的探索压力 + 夜晚防线运转的策略成就感

## 2. 核心循环

```
白天（约 3 分钟）
  离开基地 → 探索废墟/砍树/拆车 → 搜集木材·废铁·食物
  → 遇到零散丧尸（可打可跑） → 天黑前回基地 → 布置防御
夜晚（约 2 分钟）
  丧尸潮从地图边缘涌向基地 → 炮台/陷阱自动作战
  → 玩家绕后补枪/修墙（微操但压力小） → 活到天亮
结算
  存活天数 +1 → 丧尸变多变强 → 死亡时提交最高纪录
```

- 昼夜时长：白天 ~180 秒，夜晚 ~120 秒（数值放 `config.ts` 便于调参）
- 天黑前 30 秒屏幕边缘出现暗角提示"即将入夜"
- 地图：世界 **1600×1600 像素**，基地在地图中央
- 基地范围：以基地中心为圆心、**半径 240px** 的圆形区域；丧尸进入该范围后转为攻击玩家与建筑
- 白天预置 4-6 只游荡丧尸，**不刷新**；天亮时残留丧尸在 3 秒内消散
- 夜晚玩家仍可离开基地活动（高危险，自行取舍）

## 3. 资源系统

| 资源 | 来源 | 用途 |
|------|------|------|
| 木材 | 砍树、搜木板堆 | 围墙、拒马 |
| 废铁 | 搜废墟、拆废弃车辆 | 自动炮台、尖刺陷阱 |
| 食物 | 搜罐头点、击杀丧尸 15% 掉落 | 补充饥饿值 |

- 饥饿值随时间下降，归零后持续掉血；吃食物回复
- 采集方式：靠近资源点按 `E`，进度条走完获得资源，资源点耗尽后消失
- 数值锚点（全部放 `config.ts`）：
  - 初始资源：木材 **20**、废铁 **8**、食物 **2**
  - 单个资源点产量 **3-5** 个单位，采集耗时 **2 秒**
  - **初始资源点**：地图生成 **40 个**，木材:废铁:食物 ≈ **4:4:2**（树 / 废墟车辆 / 罐头点）
  - **资源点再生**：每晚结算后重生 **15 个**资源点（约 60 单位，与单日采集上限持平），地图上残存资源点总数封顶 **60** 个，防止无限囤积
  - 调整依据：若每晚只回 6 个（24 单位），玩家单日采集 60 会持续净亏，第 4 天资源见底而丧尸仍在变强，无尽模式必死
  - 饥饿上限 **100**，每 **6 秒 -1**；归零后每秒 **-2 HP**；每份食物 **+25**

## 4. 建造系统

- 建造模式：按 `B` 进入，幽灵预览 + 网格吸附，`1-4` 切换建筑，`Esc`/`B` 退出
- 建筑数值表（`config.ts`）：

| 建筑 | 造价 | 耐久 | 效果 |
|------|------|------|------|
| 木墙 | 5 木材 | 150 | 阻挡通行，被啃咬扣耐久 |
| 自动炮台 | 15 废铁 | 80 | 射程 300，射速 1 发/秒，伤害 10 |
| 拒马 | 8 木材 | 150 | 范围内丧尸减速 50%，每秒 2 伤害 |
| 尖刺陷阱 | 10 废铁 | 60 | 驻留敌人每秒 8 伤害，自身每秒 -1 耐久 |

- 建造网格：**32px 步长**，建筑占 1 格；幽灵预览按格吸附，**视觉框画成 32×24 压扁矩形**（见第 9 节）
- 建筑不能与资源点、玩家重叠；地图中央为初始基地（预置一小圈木墙）
- 木墙可手动修理：靠近按 `E`，每 1 秒回复 **15** 耐久，消耗 1 木材
- 平衡依据：3 只普通尸同时啃墙 = 12 DPS，150 HP 墙约 12.5 秒破；玩家修理 15/秒可勉强压回，这是"绕后修墙"微操的价值来源



## 5. 丧尸设计

| 类型 | 出现条件 | HP | 速度 | 对玩家伤害 | 对建筑伤害 | 特性 |
|------|----------|-----|------|-----------|-----------|------|
| 普通尸 | 第 1 夜起 | 30 | 40 | 8/秒 | 4/秒 | 慢速、扎堆、优先啃挡路的建筑 |
| 奔跑者 | 第 3 夜起 | 20 | 90 | 6/秒 | 3/秒 | 快速、会绕开障碍物 |
| 胖尸 | 第 5 夜起 | 120 | 30 | 12/秒 | 10/秒 | 死亡自爆，3 格范围内造成 40 建筑伤害 |

> 对玩家伤害与对建筑伤害是**两套独立数值**。沿用同一数值会让墙在 1-2 秒内被拆穿，塔防直接失效。

- 波次公式（`config.ts`）：
  - 普通尸数量 = `6 + 天数 × 3`
  - 第 3 夜起奔跑者占总数 25%；第 5 夜起胖尸每夜 1 只，每 5 天 +1
  - 每第 5 天为**尸潮夜**，数量翻倍并在入夜 15 秒前警告
- **入场节奏**：丧尸不一次性刷出。入夜后以**每 0.8 秒 1 只**的速度从地图四边随机位置入场，直到波次总数发完；同场达上限时暂停入场
- 同场丧尸**上限 150**（配合对象池复用）
- **数量封顶后的难度成长**：第 20 夜起，丧尸 HP 每夜 **+5%（复利）**，补偿数量不再增长导致的难度停滞
- **寻路：完整网格 A***
  - 底层 16px 网格；建筑占 2×2 格
  - **建筑在 A\* 中是"高代价可通行"节点**（通行代价 8，空地 1）——丧尸优先绕路，无路可绕时选择最便宜的挡路建筑直接攻击。这样同时满足"会绕障碍"和"会啃墙"
  - **时间分片**：每帧最多处理 8 只丧尸的路径请求，其余沿用已有路径
  - **路径缓存**：目标点移动不足 2 格且路径未被新建筑阻断时，不重算
  - 丧尸 AI 优先级：攻击玩家 → 啃咬挡路建筑 → 直奔基地核心
- **玩家死亡即游戏结束**，基地核心不可破坏，仅作为夜间目标锚点
- 击杀丧尸 15% 概率掉落食物

- 玩家无冲刺/翻滚，被围只能靠走位和射击脱身


## 7. 技术架构

- 技术栈：**Phaser 3 + TypeScript + Vite**，Node 20+
- HUD/菜单使用 **DOM 覆盖层**（不塞进 canvas）；最高纪录存 `localStorage`
- 核心边界：
  - `sim/` 纯模拟层，**不 import Phaser**，游戏规则全在此层，可独立单测
  - 场景（scenes/）是薄的：每帧读取 GameState → 同步精灵/动画/相机
  - 输入映射集中在输入系统一处，映射为语义动作（move/interact/build/select-1..4/attack/cancel/pause）
- 目录结构：

```
wasteland-dawn/
├── index.html
├── package.json
├── tsconfig.json
├── vite.config.ts
└── src/
    ├── main.ts            # 入口
    ├── config.ts          # 数值表：昼夜时长、建筑属性、波次公式
    ├── manifest.ts        # 资产清单：稳定 key → 文件路径
    ├── sim/               # 纯模拟层
    │   ├── GameState.ts   # 唯一可变状态源（可序列化）
    │   └── systems/       # 昼夜、采集、建造、丧尸AI、战斗、波次
    ├── scenes/
    │   ├── BootScene.ts   # 预加载
    │   └── GameScene.ts   # 主场景
    ├── view/              # 2.5D 渲染层：精灵工厂、底部锚点、深度排序、脚底阴影、相机跟随
    ├── ui/                # DOM HUD（资源条、建造菜单、结算面板）
    └── assets/            # characters/ environment/ ui/ fx/ audio/
```

- 存档边界：只存最高纪录（存活天数 + 击杀数），不存进行中战局（无尽模式单局即弃）

## 8. UI 表面（DOM HUD）

- 顶部：第 N 天 + 昼夜进度条
- 左下：木材/废铁/食物数量 + 饥饿条
- 右下：建造菜单（建筑图标 + 价格 + 快捷键）
- 夜晚：波次来袭提示
- 主菜单：开始 / 最高纪录展示
- 死亡结算：存活天数 + 总击杀 + 是否破纪录 + 重新开始

## 9. 视角与渲染投影

- **视角类型**：倾斜顶视（tilted top-down 2.5D），参考《饥荒》
- **不是真等距**：世界仍是**轴对齐正方形网格**，不做 45° 菱形旋转。寻路、碰撞、建造坐标与正顶视完全一致，改动只发生在渲染层
- **投影规则**：
  - 精灵锚点统一 `setOrigin(0.5, 1)`，即**底部中心对齐地面点**
  - 深度排序 `depth = 脚底世界 y`：树、建筑、角色、丧尸全部参与，实现"前面的挡住后面的"
  - 每个立体物件在脚下绘制椭圆阴影，强化"站立"感 —— 这是 2.5D 最关键的视觉语言
  - 角色**始终面向镜头**，只用 `flipX` 区分左右，**不随移动方向旋转**（单帧素材一旋转就穿帮，会露出"背面还是正面"）
- **地面表现**：瓦片美术画成斜俯视砖块（顶宽底窄），但逻辑网格仍是正方形
- **建造预览**：幽灵框画成 `32×24` 的压扁矩形（Y 方向 0.75 倍），暗示倾斜地面；实际占格仍是 `32×32`
- **相机**：跟随玩家并 clamp 到世界边界，无缩放
- **性能**：深度排序交给 Phaser 内置 `depth` 属性，不需要每帧手动排序（200 个对象设置 depth 的开销可忽略）
- **代价（明确记录）**：需要"带高度"的树木与建筑美术；正上方俯拍的素材（如圆盘状树冠）不能直接使用

## 10. 美术与资产管线

- **目标风格（最终交付标准）**：16-bit 像素风，暖褐土黄主调，低饱和废土配色
- **Phase 1 占位素材**：Kenney CC0 包
  - `Top-down Shooter`：角色/丧尸立绘（6 种姿态）、室内瓦片（**本作不用**，仅备用）
  - `Tower Defense (Top-down)`：户外草地/泥土方块（地面主用）、炮塔、投射物、墙体
  - 环境来源分工：地面与建筑取 TD 包，角色取 Shooter 包 —— 两包同风格同网格，可混用
  - 授权 **CC0 1.0**，可商用，作者 Kenney Vleugels（Kenney.nl），原始 License 存于 `src/assets/licenses/`
  - **已知风格差异**：Kenney 是扁平矢量高饱和风，与目标像素风不一致，仅用于跑通玩法，**不作为最终美术**
- **替换机制（关键）**：所有资产通过 `manifest.ts` 的稳定 key 引用，Phase 3 整体换图时**游戏代码零改动**
- **占位期角色表现**：素材为单帧立绘（33×43），**不旋转**，仅 `flipX` 左右翻转 + 轻微呼吸缩放
  - 与视角的关系：Kenney top-down 角色本就是 45° 斜俯视立绘，天然适配倾斜顶视；它不适合的是"正上方俯拍"表现
  - 代价：角色转向时不改变朝向（永远面向镜头），在尸群里靠 tint 与轮廓描边区分，不靠朝向
- **树木（已解决）**：Kenney 两包均无带高度的树（只有正上方圆冠灌木，不适配倾斜顶视）。已用 AI 生成 3 种废土树，沿用 Kenney 的扁平粗描边风格：
  - `environment/trees/tree-dead.png` 枯树、`tree-oak.png` 半死阔叶、`tree-pine.png` 枯松
  - 统一 **128×144 画布、底部锚点、高度约 130-136px**（约角色高度的 3 倍），透明底
  - 处理方式：白底四角洪泛填充 + 中性白兜底去洞 + 按 alpha 裁切 + LANCZOS 等比缩放
  - 生成参数与中间文件不入库，仅保留最终 PNG
- **仍缺的高度素材**：拒马、尖刺这类矮障碍走代码绘制 + 阴影即可，不单独生成美术
- **阴影层**：所有站立物件（角色、丧尸、树、建筑）统一在脚底画椭圆阴影，是 2.5D 成立的关键；阴影不参与深度排序，固定绘制在物件之下
- **丧尸变种区分**：复用 `Zombie 1` 单帧，奔跑者绿色 tint + 1.1x，胖尸暗红 tint + 1.35x（零美术成本）
- **素材缺口**：UI 图标（木/铁/食、建造图标）Phase 1 用纯 CSS 色块 + 文字，Phase 2 再补 Kenney Game Icons
- 显示：逻辑分辨率 **960×540**，Phaser `scale.mode = FIT` + `pixelArt = true`，整数倍缩放
- 视野：v1 **无战争迷雾**，全图可见（简化实现，恐怖感靠夜晚配色与音效营造）
- **终版**像素精灵使用 sprite-pipeline 生成并规范化：统一调色板、16×16（角色/物件）/ 32×32（建筑）网格
- 地图：TS 常量程序化生成（撒树、废墟、车辆、罐头点），中央固定基地

## 11. 分期范围

1. **Phase 1 可玩核心**：Kenney 占位素材导入 + `manifest.ts` 资产层、**2.5D 渲染层（底部锚点 + 深度排序 + 脚底阴影）**、音频层（BGM 循环 + 射击/建造/命中/UI 四类 SFX）、玩家移动与射击、昼夜循环、三种资源采集、墙+炮台建造、普通丧尸波次、**网格 A* 寻路（时间分片+路径缓存）**、对象池、死亡与纪录
2. **Phase 2 内容**：奔跑者/胖尸变种、饥饿与食物、尸潮夜、拒马/尖刺陷阱、木墙手动修理
3. **Phase 3 打磨**：音效打磨（丧尸嘶吼/脚步/混音与昼夜动态）、粒子（枪口火焰/尸群血雾）、暗角滤镜、数值平衡

> 注意：Phase 1 的"饥饿"仅在 spec 中定义数值，实际生效放 Phase 2；Phase 1 里食物只作为可采集资源，暂不扣饥饿。


## 12. 测试策略

- `sim/` 核心系统单元测试：波次数量公式、建造扣费与占用校验、战斗伤害结算、昼夜切换、**A\* 路径绕障正确性**（有墙/无墙两种场景）
- 测试文件与源码同目录或 `__tests__/`，命名 `*.test.ts`
- `sim/` 层核心模块单元测试覆盖率 **≥ 80%**
- 每阶段结束浏览器试玩走查：HUD 可读性、帧率稳定（目标 60fps @ 150 丧尸）、循环完整度

## 13. 实现风险与对策

| 风险 | 影响 | 对策 |
|------|------|------|
| A\* 在 150 丧尸下卡帧 | 夜间体验崩坏 | 时间分片（每帧 8 只）+ 路径缓存 + 对象池；先做 50 只压测再放开 |
| 建筑作为"高代价节点"导致丧尸集体穿墙 | 防线失去意义 | 用高代价而非 0 代价，并限制"啃墙"只在目标不可达时触发 |
| 数值失衡（墙太脆 / 太肉） | 塔防玩法失效 | 全部数值集中在 `config.ts`，Phase 3 专门做平衡调参 |
| 无尽模式后期资源枯竭 | 玩家被动等死 | 每晚重生 **15** 个资源点，保持产出与消耗持平 |
| DOM HUD 与 canvas 输入冲突 | 点击 UI 时误触发射击 | HUD 容器统一 `pointer-events: none`，仅按钮区域开启 |
| 占位素材（Kenney 扁平风）与目标像素风差异大 | Phase 3 返工风险 | 严格走 `manifest.ts` 换图，禁止在业务代码里写死路径；Phase 3 只替换图片文件 |
| 素材为单帧立绘且不旋转，尸群中朝向无差异 | 夜间可读性下降 | 变种用 tint + 缩放区分；主角用高对比轮廓描边 + 脚下高亮圈 |
| 2.5D 遮挡：树或建筑挡住玩家 | 战斗中丢失角色位置 | 玩家头顶常驻小箭头指示；遮挡玩家的物件自动半透明化 |
