# 项目汇总与待办

> 《求生 Survival》进度跟踪。数值细节以[设计文档](superpowers/specs/2026-10-28-fps-town-design.md)为唯一事实源。

## 一、项目概况

| 项 | 内容 |
|---|---|
| 类型 | 浏览器第一人称射击（Three.js / WebGL2） |
| 场景 | 程序化生成的废土小镇，固定种子，零外部素材 |
| 玩法 | 选装备 / 选图 → 街道探索 → 射击丧尸（4 枪 / 2 近战 / 2 投掷）→ 昼夜交替（夜里丧尸视野翻倍）→ 死亡结算 |
| 技术栈 | Three.js 0.186 + TypeScript 5.9 + Vite 7.3（版本固定），DOM HUD，无后端 |
| 架构 | sim（纯 TS 模拟层，禁 import three）/ render（Three 渲染）/ ui（DOM HUD）/ audio（WebAudio 合成） |
| 代码量 | 34 个 TS 文件约 7500 行 |
| 远端 | https://github.com/NingDuiYan/Wasteland_Dawn.git（main） |

## 四、已知风险

| 风险 | 对策 |
|---|---|
| 阴影 pass 是最大开销（软件光栅 60→40 FPS） | 512 贴图 + PCF + 6 秒后 FPS<45 自动关闭；不要改 PCFSoft |
| 天球靠 `camera.name = 'main-camera'` 找相机 | 改名字会让天球停在世界原点 |
| HUD 点击穿透成开火 | `#hud` 是 `pointer-events: none`，可点元素必须自己写 `auto` |
| 无 Pointer Lock 环境（内嵌 webview / 无头） | 开火不依赖锁定，只有视角转动需要 |
| 天气预设成组联动 | 单独拉高一个参数会让另外三档失真，改前读设计文档第 3 节 |
