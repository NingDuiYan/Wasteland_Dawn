## 一、项目概况

| 项 | 内容 |
|---|---|
| 类型 | 废土求生 2.5D 浏览器游戏（饥荒式斜俯视），昼夜循环守家 |
| 玩法 | 白天探索采集（3 分钟）→ 夜晚塔防守家（2 分钟），无尽模式刷存活天数 |
| 技术栈 | Phaser 3.90.0 + TypeScript 5.9 + Vite 7.3（版本固定），DOM HUD，无后端 |
| 架构 | sim（纯 TS 模拟层）/ scenes（薄场景）/ view（2.5D 渲染规则）/ ui（DOM HUD）分层 |
| 远端 | https://github.com/NingDuiYan/Wasteland_Dawn.git（main） |

### 实测发现并已修复
1. 丧尸贴脸埋住玩家 → sim 层加 `minDistanceToPlayer: 34`
2. 变种染色 Canvas 渲染器失效 → 预烘焙染色贴图替代 setTint
3. 网格与地面棋盘格重合不可见 → 错开半格
4. 遮挡无法稳定复现 → 固定种子 + 出生点正上方固定高树
